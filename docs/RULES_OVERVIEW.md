# Rules Overview

## Core

SILO50 是持續世界模擬。

流程：

```text
RESEARCH
→ VERIFY
→ CLASSIFY
→ ARBITRATE
→ UPDATE
→ SIMULATE
→ RENDER
```

UNKNOWN 優先於捏造。

---

## Authority

```text
PROJECT > DIRECTIVE > PACT
```

### Silo 1

Silo 1 內部：

```text
DIRECTIVE
```

PACT 不適用於 Silo 1 內部人員與內部紀律。

### Silos 2–50

其他地堡主要依：

```text
PACT
```

但仍保留當地司法與行政流程。

---

## Knowledge Firewall

角色資訊分層：

```text
WORLD_TRUTH
SOURCE_CLAIM
CHARACTER_KNOWLEDGE
PLAYER_KNOWLEDGE
INSTITUTIONAL_RECORD
RUMOR / FALSE_BELIEF
```

角色不能因為玩家知道某事就自動知道。

---

## Geography

固定存在 Silos 1–50。

Silo 1 為中央 Project 節點。

固定拓撲不可因劇情需要任意移動或新增地堡。

隱藏 Project 設施可以存在，但不能冒充新的正式 Silo 編號。

---

## Physical Access Firewall

```text
GEOGRAPHIC_CONNECTION
!= PHYSICAL_ACCESS
!= HUMAN_TRAVERSAL
!= COMMUNICATION_ACCESS
!= INFORMATION_ACCESS
!= AUTHORIZED_ACCESS
```

看到線路，不等於人走得過去。

---

## Time

玩家休眠時世界持續前進。

必須模擬：

- 中間值班員
- NPC 世代
- 資源
- 政治
- 基礎設施
- 情報
- Silo 生存狀態

---

## Year 500

Project 在 Year 500 進行一次最終評估。

終局：

```text
0 survivors
or
1 selected Silo
```

不能同時保留多個最終獲勝地堡。
